create *.gvintermediate(image seq) from any video file
ruby video_to_gvintermediate.rb footage.mov

カレントフォルダの全てのmp4に対し、create *.gvintermediate(image seq) from any video file
find . -maxdepth 1 -type f -iname '*.mp4' -print0 | while IFS= read -r -d '' f; do ruby video_to_gvintermediate.rb "$f"; done

指定の.mp4からロスレスで音声だけを.wavで抜き出す。元のチャンネル構成をそのまま保つ
ffmpeg -i input.mp4 -map 0:a:0 -vn -c:a pcm_s16le output.wav

カレントフォルダの全てのmp4に対し、ロスレスで音声だけを.wavで抜き出す。元のチャンネル構成をそのまま保つ
find . -maxdepth 1 -type f -iname '*.mp4' -print0 | while IFS= read -r -d '' f; do ffmpeg -nostdin -y -i "$f" -map 0:a:0 -vn -c:a pcm_s16le "${f%.*}.wav"; done

カレントフォルダの全mp4の、FPS・解像度をリストアップするBashのワンライナー
find . -maxdepth 1 -type f -iname '*.mp4' -print0 | while IFS= read -r -d '' f; do read -r w h fps <<< "$(ffprobe -v error -select_streams v:0 -show_entries stream=width,height,avg_frame_rate -of default=nw=1:nk=1 "$f" | tr '\n' ' ')"; printf '%s\t%dx%d\t%.3f fps\n' "${f#./}" "$w" "$h" "$(awk -v v="$fps" 'BEGIN{split(v,a,"/"); print a[2] ? a[1]/a[2] : a[1]}')"; done

320x420や、640x480のmp4を、左右にレターボックスをつくったりして拡大して中央に配置した1920x1080の動画に変換する
ffmpeg -i input.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black,setsar=1" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a copy output_1920x1080.mp4
複数ファイルを一括変換する
for f in *.mp4; do ffmpeg -i "$f" -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black,setsar=1" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a copy "${f%.mp4}_1920x1080.mp4"; done
320x420や、640x480、1440x1080のmp4と、1920x1080のmp4があります。それらを、1920x1080じゃないものに限り、上下左右に適切にレターボックスをつくったりして拡大して中央に配置した1920x1080の動画に変換するBashのワンライナー
find . -maxdepth 1 -type f -iname '*.mp4' -print0 | while IFS= read -r -d '' f; do res=$(ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=s=x:p=0 "$f"); if [ "$res" != "1920x1080" ]; then echo "Converting and replacing: $f ($res)"; tmp="${f}.tmp"; if ffmpeg -nostdin -y -i "$f" -map 0:v:0 -map '0:a?' -vf "scale=1920:1080:force_original_aspect_ratio=decrease:force_divisible_by=2,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black,setsar=1" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -c:a copy -movflags +faststart -f mp4 "$tmp"; then mv -f -- "$tmp" "$f"; else echo "Failed: $f"; rm -f -- "$tmp"; fi; else echo "Skipping: $f (already 1920x1080)"; fi; done

カレントフォルダの全てのmp4に対し、フレームレートが29.970じゃないものは、可能な限りクオリティを維持して29.970に変換して上書きするBashのワンライナー
find . -maxdepth 1 -type f -iname '*.mp4' -print0 | while IFS= read -r -d '' f; do fps=$(ffprobe -v error -select_streams v:0 -show_entries stream=avg_frame_rate -of csv=p=0 "$f"); if [ "$fps" = "30000/1001" ]; then echo "Skipping: $f ($fps)"; else tmp="${f%.*}.tmp.mp4"; echo "Converting: $f ($fps -> 30000/1001)"; ffmpeg -nostdin -y -i "$f" -map 0 -vf "fps=30000/1001" -c:v libx264 -preset slow -crf 12 -c:a copy -c:s copy -map_metadata 0 -movflags +faststart "$tmp" && mv -f "$tmp" "$f"; fi; done
